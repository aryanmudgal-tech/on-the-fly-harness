# On-the-fly harness

Research program on **agent harnesses**: what they are, who builds them, where the field is going, and a proposal for reimagining the default harness so it works for developers *and* non-technical people.

**Status:** brainstorming. Open questions are out to the author before the research fan-out starts.

## How to read this repo

| Path | What it is |
|------|------------|
| `docs/00-brief.md` | The research brief: framing, working definitions, assumptions, open questions, proposed workstreams |
| `docs/superpowers/` | Design specs and execution plans (superpowers methodology) |

More sections are added as the research lands. Every document states its sources.
